# G3 집 외관 평가

## 판단 근거

G0 아트 디렉션·GRAPHICS_PLAN, G2 최종 README, UI_DESIGN_GUIDE §1·6·8, BLUEPRINT_V3의 지상 마을/집 생활 방향과 COLLABORATION을 기준으로 삼았다. 기존 집은 이미 초록 기와 지붕, 목조 벽과 돌 기단, 따뜻한 쌍창, 꽃상자, 굴뚝이 잘 읽힌다. 84×73의 작은 집을 큰 저택이나 성채로 바꿀 이유가 없다. G2의 작업대·모루·선반을 반복하면 집과 공방의 역할 구분이 약해지므로 생활 물건만 제한적으로 비교했다.

| 기준 | A | B | C |
|---|---|---|---|
| 따뜻함 | 기존 창빛 유지 | 창빛 + 앉을 곳/식물로 가장 높음 | 따뜻하나 금속 회색이 소량 추가 |
| 주거 가독성 | 기존과 동일 | 세 안 중 가장 명확 | 공방보다 조용하지만 재료 수납처럼 보일 여지 |
| 기존 장점 보존 | 가장 높음 | 초록 지붕·창·꽃·입구 유지 | 초록 지붕·창·꽃 유지 |
| G2와 정합 | 목재/기단 명암 정리 | 생활/제작 역할 대비가 좋음 | 구리·목재·회색 금속 팔레트 연결이 가장 직접적 |
| 모바일 | 단순하고 안전, 차이가 약함 | 화분은 보이지만 의자 세부는 작음 | 굴뚝 띠/상자의 작은 차이가 약함 |
| 저녁 | 창/문이 중심 | 창빛 주변 생활 물건이 차분하게 남음 | 금속 상자는 그늘에 묻힘 |

## 권고

**B를 우선 후보로 권고**한다. G1 옆에서 크기가 커지지 않고, 실제 PC/모바일 화면에서 기존의 아늑함을 유지하며 현관 주변의 작은 생활 흔적이 추가된다. 추천 근거는 장식 개수가 아니라 주거 용도의 읽힘이다. 가장 절제된 결과를 원하면 A도 적합하다. C는 G2와 색/재질을 맞추는 데 유리하지만 집의 독립적인 생활감은 B보다 약하다.

A의 한계는 기존 v2가 이미 입체적인 재질을 갖고 있어 실게임에서 변화가 작다는 점이다. B의 한계는 모바일에서 의자의 얇은 다리보다 밝은 좌판/화분 색덩어리가 먼저 보인다는 점이다. C의 한계는 작은 금속 상자가 집 수납인지 설비인지 즉시 읽히지 않을 수 있다는 점이다. 어느 안도 새 광원이나 건물 확장, 충돌 변경을 요구하지 않는다.

## 승인 후 범위

선택된 안의 외관만 별도 적용한다. 현재 PR은 비교 자료이며 실내/가구 상호작용·정원·월드 배치·박물관 G4는 포함하지 않는다. 문/계단·기준점·기존 광원·세이브를 보존하는 동일한 계약을 적용 PR에서도 확인해야 한다.
