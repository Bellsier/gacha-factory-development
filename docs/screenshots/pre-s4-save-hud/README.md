# 저장 HUD 수정 전후

기준224b3da CSS/runtime과 수정 UI를 같은 격리 프로필·마을·뷰포트에서 비교했다. 인부/연구/납품은 중간, 박물관은 하단 스크롤이다. HUD 공간 예약으로 스크롤 최대값이 바뀌므로 같은 상대 위치에서도 보이는 문단은 일부 달라질 수 있다.

화면은 표시용 박물관/인부 fixture이며 전체 플레이 완료를 뜻하지 않는다. 모든 상/중/하단, 일반 월드·저장 메뉴·추가 화면 크기는 CI artifact에 포함한다.
