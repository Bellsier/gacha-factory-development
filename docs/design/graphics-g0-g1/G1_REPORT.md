## 1. 바꾼 점

| 부위 | 현재 | 시안 |
|---|---|---|
| 측면 다리 | 두 다리가 붙음(간격 0px), 명도 차이로만 구분 | 먼 다리를 1px 떨어뜨리고 한 단계 어둡게(바지 `#4a4d52`, 장화 `#9a6c3a`) |
| 측면 보폭 | 앞뒤 ±1px, 뒤 발 1px 들림 | 앞뒤 ±2px(사선 다리), 뒤로 간 발 뒤꿈치 1px 들림 |
| 측면 팔 | 같은 쪽 다리와 함께 앞뒤로 ±1px | 다리와 반대 위상, 범위 3px, 뒤 가장자리 1px 그늘 |
| 정면 다리 | 디딤발 1px 들림 | 디딤발 2px 들림(무릎 굽힘) |
| 후면 다리 | 디딤발 1px 들림 | 1px 들림 + 1px 안쪽으로(배낭·옷자락에 가리지 않게) |
| 앞·뒤 팔 | 한쪽만 1px 내려감 | 한쪽 위·한쪽 아래(차이 2px), 소매 안쪽 1px 그늘 |
| 유지 | — | 16×22, 발 기준선(행 20), 머리 끝(행 0), H 21px, 코발트 머리, 몸 흔들림 1px, 4프레임 주기 |

## 2. 수치 (비교 화면이 직접 계산)

| 방향 | 대기↔걸음 다리 부분 차이(px) 현재 → 시안 | 걸음1↔걸음3 현재 → 시안 | 측면 대기 다리 행 덩어리 수 |
|---|---|---|---|
| 측면(classic) | 34 → **47** | 22 → 23 | 1 → **2** |
| 측면(v2) | 38 → **47** | 28 → 24 | 1 → **2** |
| 정면(classic) | 28 → 22 | 34 → 36 | (정면은 원래 2) |
| 후면(classic) | 23 → 25 | 28 → 32 | — |

- 정면의 대기↔걸음 차이가 줄어든 이유: 2px 든 발 일부가 옷자락에 가립니다. 대신 팔 높이 차이(2px)가 생겼고, 걸음끼리의 차이는 늘었습니다.
- 4개 그림 모두 16×22, 머리 끝 행 0, 발 끝 행 20입니다.

## 3. 실제 게임 화면 확인

- 배포본에서 시험 브라우저 안의 `tdPlayerSprite`만 시안으로 바꿔 끼웠습니다(classic과 v2, PC와 휴대폰).
